# DOCX 格式化 Skill 测试用例

## 测试环境准备

```bash
pip install python-docx
```

## 测试用例 1：党政机关公文

### 输入文件特征
- 普通Word文档，标题加粗
- 页边距为默认值（上下左右均2.54cm）
- 正文字体为宋体小四
- 无红色分隔线，无公文版头

### 预期输出
| 修改项 | 修改前 | 修改后 |
|--------|--------|--------|
| 上边距 | 25.4mm | 37mm |
| 左边距 | 25.4mm | 28mm |
| 正文字体 | 宋体 | 仿宋_GB2312 |
| 正文字号 | 12pt(小四) | 16pt(三号) |
| 文档网格 | 无 | 22行×28字/页 |
| 层级序号字体 | 统一宋体 | 黑体/楷体/仿宋/仿宋四级区分 |
| 标题字体 | 宋体加粗 | 小标宋体二号 |

### 运行命令
```bash
python3 scripts/docx_formatter.py \
  --input tests/samples/test_gov_input.docx \
  --template templates/government_document.json \
  --output tests/samples/test_gov_output.docx \
  --report tests/samples/test_gov_report.json
```

### 验证要点
- [ ] 打开输出文件，检查页边距上37mm左28mm
- [ ] 检查正文为仿宋三号
- [ ] 检查文档网格设置为22行×28字
- [ ] 检查层次序号一级"一、"为黑体、二级"（一）"为楷体
- [ ] 确认正文文字内容未被修改

## 常见测试问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 输出文件字体未变化 | run.font.name 未设置 eastAsia | 检查 _format_run 中 rFonts 设置 |
| 暗标仍有加粗 | 表格内或页眉页脚未遍历 | 检查 _clear_bold 是否遍历了所有区域 |
| 公文每页行数不正确 | 未设置文档网格 | 检查 _set_grid_lines 是否调用了 docGrid |
| 检测报告分区不生效 | 关键词匹配失败 | 检查 detection_keywords 与实际文档文本 |
| 中英文字体未分开 | run.font.name 只设了一个 | 需同时设置 eastAsia 和 ascii/hAnsi |
